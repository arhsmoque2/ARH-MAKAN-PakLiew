# Source Notes

Version: v0.1

These sources were used as register references, not as copy to reproduce verbatim.

## Official / institutional event language

- JKR and related public-works materials: useful for `majlis`, `program`, `bengkel`, `sesi taklimat`, `kursus`, `program CSR`, and technical/operational event grammar.
- Lembaga Lebuhraya Malaysia (LLM): useful for `sesi taklimat`, `majlis perhimpunan`, `amanat tahun baharu`, and formal internal event notices.
- KWSP: useful for recognition/appreciation register, including `Majlis Makan Malam Tahunan Anugerah` and `mengiktiraf prestasi cemerlang`.
- PETRONAS: useful for large-corporate hybrid register where BM ceremonial titles coexist with retained English media or brand terms, e.g. `Pratonton Eksklusif`, `Filem Web`, `Bersama Media`.
- SME Corp / MDEC: useful for PMKS/PKS ecosystem language such as `platform`, `pemadanan perniagaan`, `kolaborasi`, `rakan strategik`, `penyelesaian digital`, `pembiayaan operasi`, and `transformasi digital`.
- MyCEB: useful for business events taxonomy such as corporate meetings, incentives, conventions, exhibitions, seminars, workshops, dialogue sessions, networking opportunities, and media events.

## Use notes

```text
Use official sources to infer register.
Do not copy press-release language directly unless writing an institutional-style notice.
For venue marketing, adapt official phrasing down to small-scale, truthful event language.
```
