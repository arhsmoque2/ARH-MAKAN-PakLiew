# Terminology Notes

## Private is not always peribadi

```yaml
private_mapping:
  person_or_data:
    use: [maklumat peribadi, barang peribadi, pendapat peribadi]
  privately_owned_or_guest_only:
    use: [kolam renang persendirian, bilik persendirian, rumah persendirian, penginapan persendirian]
  enclosed_or_not_public:
    use: [laman tertutup, ruang tertutup, majlis tertutup, kawasan tertutup]
```

## Exclusive is not a generic upgrade word

```yaml
eksklusif:
  best_with: [ruang, penginapan, akses, pakej, majlis]
  avoid_with: [kolam, dapur, tandas, basic facilities]
```

## Space terms

```yaml
space_terms:
  ruang: general functional space
  ruangan: copy rhythm / section / room-like space
  laman: warm hospitality outdoor yard
  halaman: house-front or home yard
  pekarangan: formal compound / grounds
  sudut: corner / small feature area
```

Avoid `perkarangan rumah`; use `pekarangan rumah`.

## Corporate event terms

```yaml
corporate_terms:
  sesi: session
  majlis: organized/ceremonial event
  program: structured initiative/activity
  bengkel: workshop / hands-on session
  taklimat: briefing / explanation
  seminar: seminar / knowledge session
  dialog: dialogue / two-way engagement
  luncheon: corporate lunch event, often retained
  networking: retained or localized as jaringan perniagaan
  business_matching: retained or localized as pemadanan perniagaan
```
