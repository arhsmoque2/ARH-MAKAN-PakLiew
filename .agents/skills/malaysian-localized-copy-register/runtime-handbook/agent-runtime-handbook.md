# Agent Runtime Handbook - Malaysian Localized Copy Register

Version: v0.1

Use: runtime / brownfield / debugging / pressure repair.

## Core rule

Do not translate isolated words. Translate:

```text
intent + object + register + surface + audience
```

## Runtime question order

```text
1. What is the surface?
2. What is the audience?
3. What is the register?
4. What is the object?
5. What is the safest phrase family?
```

If time is short: use clean English-base copy with restrained Malay anchors. Do not force slang. Do not force formal BM if unsure.

## Register families

### Hospitality / leisure

Use for family weekends, private pool stay, holiday stay, small family gathering.

Use:

```text
hujung minggu yang santai
ruang berkumpul keluarga
kolam renang persendirian
laman tertutup
ruang makan bersama
privasi keluarga
penginapan eksklusif
```

Avoid: `sesi taklimat`, `majlis rasmi`, `stakeholder`, `healing giler`, `luxury tranquility`, corporate jargon.

### Weekday event venue

Use for weekday bookings, small events, seminars, book clubs, association meetings, luncheons, appreciation events, small private ceremonies.

Use:

```text
ruang tempahan hari bekerja
ruang acara berskala kecil
ruang seminar kecil
ruang majlis tertutup
jamuan korporat kecil
sesi separuh hari
sesi sehari penuh
```

Avoid: `weekend escape`, `cuti-cuti`, `holiday package`, `family vacation`, `staycation` except casual promo.

### Corporate / SME / GLC

Use for SME meeting, corporate luncheon, vendor briefing, client appreciation, staff appreciation, training, workshop, seminar, committee meeting.

Use:

```text
sesi taklimat
sesi penerangan
sesi perbincangan tertutup
bengkel
seminar kecil
majlis penghargaan
majlis apresiasi
jamuan korporat
luncheon korporat
pemadanan perniagaan
jaringan perniagaan
rakan strategik
```

Retain English when natural: SME, GLC, MoU, CSR, vendor, client, team building, business matching, networking, luncheon, offsite, retreat, platform, digital.

Avoid: `port healing`, `lepak corporate`, `staycation korporat`, `cuti-cuti company`, `ballroom replacement`, `conference centre`, `dewan persidangan` unless true.

### Institutional announcement

Use for agency-style announcement, formal invitation, official briefing, launch, MoU signing, CSR programme, award dinner, annual address.

Use:

```text
majlis perasmian
majlis pelancaran
majlis menandatangani MoU
sesi dialog
sesi taklimat
majlis perhimpunan
amanat tahunan
program tanggungjawab sosial korporat
majlis makan malam anugerah
```

Avoid: `jom join`, `santai-santai`, `healing`, `port`, `best giler`.

### Social / promo

Use for Instagram, TikTok, WhatsApp blast, story promo, casual SME promo.

Allowed: `jom`, `vibe`, `healing`, `OOTD`, `port`, `lepak`, `promo`, `weekday slot`.

Avoid in main website/corporate pages: `best giler`, `healing korporat`, `port meeting`, `lepak dengan boss`.

## Phrase composition rules

```text
private + pool       -> kolam renang persendirian
private + courtyard  -> laman tertutup
private + event      -> majlis tertutup
private + discussion -> perbincangan tertutup
private + room       -> bilik persendirian
private + data       -> maklumat peribadi
private + belongings -> barangan peribadi
```

```text
exclusive + space   -> ruang eksklusif
exclusive + stay    -> penginapan eksklusif
exclusive + access  -> akses eksklusif
exclusive + package -> pakej eksklusif
exclusive + event   -> majlis eksklusif
```

```text
family gathering        -> ruang berkumpul keluarga
dining space            -> ruang makan bersama
event space             -> ruang majlis tertutup
seminar space           -> ruang seminar kecil
workshop space          -> ruang bengkel
discussion space        -> ruang perbincangan tertutup
courtyard/enclosed yard -> laman tertutup
house compound          -> pekarangan rumah
quiet corner            -> sudut tenang
BBQ area                -> ruang BBQ / sudut BBQ
```

## Pressure fallback lines

Hospitality:

```text
Penginapan eksklusif dengan kolam renang persendirian, laman tertutup dan ruang berkumpul keluarga.
```

Weekday event:

```text
Ruang tempahan hari bekerja untuk mesyuarat kecil, seminar, luncheon dan majlis tertutup.
```

Corporate / SME:

```text
Ruang tertutup untuk sesi taklimat, perbincangan, luncheon korporat dan majlis penghargaan berskala kecil.
```

Institutional:

```text
Sesi ini bertujuan memberi penerangan kepada peserta serta membuka ruang perbincangan bersama pihak berkepentingan.
```
