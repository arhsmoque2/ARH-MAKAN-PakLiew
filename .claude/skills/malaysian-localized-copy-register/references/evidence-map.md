# Evidence Map

Version: v0.1

## Business-events taxonomy

MyCEB positions business events around corporate meetings, incentives, conventions, exhibitions, seminars, workshops, dialogue sessions, networking opportunities, and media events. This supports a weekday-event register that is more than leisure/homestay copy.

Adopted patterns: private weekday venue, meetings, seminars, workshops, dialogue sessions, networking, media events, corporate meetings.

## Institutional event grammar

JKR/LLM-style public-sector materials show repeated use of: majlis, program, sesi taklimat, bengkel, kursus, sesi dialog, perhimpunan, amanat, MoU, CSR.

Adopted patterns: sesi taklimat, sesi penerangan, bengkel, majlis pelancaran, majlis penghargaan, program CSR.

## Recognition language

KWSP-style finance/institutional copy supports: majlis makan malam anugerah, mengiktiraf prestasi cemerlang, pencapaian, warga kerja, rakan niaga.

Adopted patterns: majlis penghargaan, majlis apresiasi, jamuan penghargaan, mini award ceremony.

## Large-corporate hybrid BM + English

PETRONAS-style copy supports hybrid corporate phrases where BM event framing coexists with retained English media/brand language.

Adopted patterns: Majlis Berbuka Puasa, Pratonton Eksklusif, Filem Web, Bersama Media, memperkukuh hubungan, program komuniti.

## SME / digital ecosystem language

SME Corp/MDEC-style copy supports: PMKS, PKS, platform, pemadanan perniagaan, jaringan perniagaan, kolaborasi, rakan strategik, penyelesaian digital, pembiayaan operasi, transformasi digital.

Adopted patterns: sesi networking, business matching, pemadanan perniagaan, jaringan perniagaan, bengkel pendigitalan, latihan keusahawanan.

## Hospitality phrase compatibility

This pack treats hospitality terms as relationship-based rather than dictionary-based:

```text
private + pool       -> kolam renang persendirian
private + courtyard  -> laman tertutup
exclusive + space    -> ruang eksklusif
exclusive + package  -> pakej eksklusif
```
