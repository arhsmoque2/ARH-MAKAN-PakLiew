# Agent Evaluation Rubric

Score: 0 = fail, 1 = weak/risk, 2 = pass, 3 = strong.

## 1. Register fit

Pass: family copy sounds warm and local; weekday copy sounds purposeful; corporate copy sounds credible; institutional copy sounds formal and BM-dominant; social copy is casual but controlled.

Fail: social slang in GLC copy, holiday copy for corporate event, government bulletin tone for family stay.

## 2. Phrase compatibility

Pass: `private pool -> kolam renang persendirian`, `private courtyard -> laman tertutup`, `exclusive space -> ruang eksklusif`, `business matching -> pemadanan perniagaan`, `briefing -> sesi taklimat`.

Fail: `laman peribadi`, `kolam eksklusif`, `ruang private`, `corporate healing`, `business lepak`.

## 3. Local naturalness

Pass: reads like Malaysian-localized copy, not dictionary translation.

## 4. Truthfulness / venue scale

Pass: uses accurate terms such as `ruang seminar kecil`, `ruang majlis tertutup`, `private weekday venue`.

Fail: claims `conference centre`, `grand ballroom`, `five-star venue`, or `convention hall` without evidence.

## 5. Loanword control

Pass: retains SME, GLC, MoU, CSR, vendor, client, networking, business matching, luncheon where natural; localizes briefing, workshop, launch, appreciation when appropriate.

## 6. Slang gating

Pass: jom, vibe, healing, port, OOTD appear only in social/WhatsApp/casual caption surfaces.

## 7. Benefit + proof

Pass: mentions private pool, enclosed courtyard, dining space, parking, half-day slot, seminar setup, luncheon flow.

Fail: only says luxury, comfort, tranquility, perfect getaway, best place.

## 8. Surface action

Pass: CTA, inquiry, package, slot, event type or booking path is clear.

## 9. Brownfield repair discipline

Pass: keeps original meaning but repairs register, object phrase and proof.

## Overall strong pass

```text
Register is correct.
Phrases are object-compatible.
Copy sounds locally natural.
Claims are truthful.
Slang is gated.
User action is clear.
```
