# Register Routing Quickmap

Version: v0.1

## Fast route

```text
Family / stay / pool / weekend -> Hospitality / leisure
Weekday / seminar / luncheon / book club / association / small event -> Weekday event venue
SME / vendor / client / staff / corporate / GLC / agency -> Corporate event
Taklimat / perasmian / pelancaran / MoU / CSR / anugerah -> Institutional announcement
Instagram / TikTok / WhatsApp blast / promo -> Social promo
```

## Surface router

| Surface | Register | Tone | Avoid |
|---|---|---|---|
| Website hero | Hospitality refined / weekday event / corporate refined | clear, warm, grounded premium | slang, over-formal BM |
| Amenity card | Practical trust | direct, factual | poetic exaggeration |
| CTA button | Concise commercial | action-led | long formal sentence |
| Corporate page | Corporate event | formal, credible | leisure staycation language |
| Social caption | Social promo | local, catchy | ministry-style copy |
| WhatsApp booking | Operational + warm | clear, practical | heavy corporate words |
| Official invitation | Institutional | BM-dominant, structured | jom, lepak, healing |
| Brownfield rewrite | Runtime repair | preserve intent, fix phrase | rewriting blindly |

## Audience phrases

Family: `ruang berkumpul keluarga`, `kolam renang persendirian`, `laman tertutup`, `ruang makan bersama`, `hujung minggu yang santai`, `privasi keluarga`.

Corporate / SME: `sesi perbincangan tertutup`, `sesi taklimat`, `bengkel`, `seminar kecil`, `jamuan korporat`, `luncheon korporat`, `majlis penghargaan`.

Agency / GLC: `sesi taklimat`, `sesi penerangan`, `majlis perasmian`, `majlis pelancaran`, `sesi dialog`, `program`, `inisiatif`, `kerjasama strategik`, `pihak berkepentingan`.

Association / Community: `mesyuarat persatuan`, `perjumpaan komuniti`, `perjumpaan kelab`, `sesi dialog kecil`, `jamuan persatuan`, `ruang berkumpul tertutup`.

Social: `jom`, `vibe`, `healing`, `OOTD`, `port`, `lepak`, `promo`, `weekday slot`.

## Safe default

```text
Ruang tertutup untuk mesyuarat kecil, seminar, luncheon dan majlis berskala kecil dalam suasana yang lebih privasi dan selesa.
```
