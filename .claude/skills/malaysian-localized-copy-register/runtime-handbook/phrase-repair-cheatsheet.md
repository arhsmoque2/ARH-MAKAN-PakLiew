# Phrase Repair Cheatsheet

Version: v0.1

## Golden rule

Repair by object. Do not repair word by word.

## Private

| Bad / Risky | Repair |
|---|---|
| laman peribadi | laman tertutup |
| kolam peribadi | kolam renang persendirian |
| ruang private | ruang tertutup / ruang eksklusif |
| event private | majlis tertutup |
| private discussion | perbincangan tertutup |
| private data | maklumat peribadi |
| private belongings | barangan peribadi |

## Exclusive

| Bad / Risky | Repair |
|---|---|
| kolam eksklusif | kolam renang persendirian |
| dapur eksklusif | dapur lengkap |
| tandas eksklusif | bilik air bersih / selesa |
| ruang luxury | ruang eksklusif / ruang tertutup |
| event eksklusif | majlis eksklusif / majlis tertutup |
| luxury homestay | penginapan eksklusif |

## Space

| Bad / Risky | Repair |
|---|---|
| ruang umum keluarga | ruang berkumpul keluarga |
| perkarangan rumah | pekarangan rumah |
| kawasan kosong untuk aktiviti | laman lapang untuk aktiviti |
| ruang seminar besar | ruang seminar kecil |
| conference centre | ruang seminar kecil, unless true |
| ballroom replacement | ruang majlis tertutup |

## Facilities

| Bad / Risky | Repair |
|---|---|
| fasiliti lengkap | kemudahan lengkap |
| servis mesra | layanan mesra |
| servis event | sokongan acara / aturan majlis |
| parking premium | parking mudah / ruang parking luas |
| toilet premium | bilik air bersih |
| kitchen premium | dapur lengkap |

## Corporate events

| Bad / Risky | Repair |
|---|---|
| meeting santai with boss | sesi perbincangan tertutup |
| port meeting | ruang mesyuarat kecil |
| lepak corporate | ruang santai selepas sesi |
| corporate healing | retreat korporat / sesi offsite |
| kelas sharing | sesi perkongsian ilmu |
| workshop santai | bengkel / sesi latihan |
| appreciation party | majlis penghargaan / majlis apresiasi |
| client makan-makan | jamuan pelanggan / luncheon korporat |
| vendor lepak | sesi bersama vendor / vendor briefing |
| business lepak | sesi networking / jaringan perniagaan |
